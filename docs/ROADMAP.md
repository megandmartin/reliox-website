# Website roadmap

These are proposed improvements to the public Reliox website. They are not release promises or a roadmap for the native Mac app. Scope and acceptance criteria should be agreed in an issue before implementation.

| Priority | Improvement | A useful result |
| --- | --- | --- |
| Next | [Accessible film transcripts and captions](https://github.com/megandmartin/reliox-website/issues/1) | Visitors can follow the approved launch film and walkthrough without sound; reviewed captions match the original audio. |
| Next | [Browser interaction regression coverage](https://github.com/megandmartin/reliox-website/issues/2) | Repeatable checks cover the mobile menu, experience tabs, reduced motion and video controls across an agreed browser matrix. |
| Next | Release asset verification | A maintainer can verify the public ZIP size and SHA-256 against release metadata without a manual comparison. Downloading the app remains separate from ordinary website checks. |

Good first contributions include reproducing a browser-specific issue, clarifying an installation step or fixing an accessibility problem with a focused before-and-after example. See [how to contribute](../CONTRIBUTING.md), [open issues](https://github.com/megandmartin/reliox-website/issues) or [suggest an improvement](https://github.com/megandmartin/reliox-website/issues/new?template=feature_request.yml).

# Security reports

Please report suspected vulnerabilities privately through [GitHub’s “Report a vulnerability” form](https://github.com/megandmartin/reliox-website/security/advisories/new). You will need a GitHub account. Do not open a public issue with exploit details, credentials, private conversations or personal data.

Include the affected page or release version, the potential impact and steps to reproduce using synthetic data. Share only what is needed to understand the problem; remove tokens, contact details and private workspace content.

This repository contains the public website and distributes the Reliox Mac download. Specify whether a report concerns the website, the download or the native app so it can be reviewed in the right context. Website checks do not establish the security of the native application or its optional connections.

For a broken link, layout problem or general product question without sensitive information, use [public issues](https://github.com/megandmartin/reliox-website/issues). The [privacy page](https://www.relioxos.com/privacy/) explains the current product and website data practices.
